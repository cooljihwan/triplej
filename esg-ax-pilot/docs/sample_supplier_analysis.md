# 샘플 협력사 1곳 분석 (2025년 자가진단 · 증빙 · 개선계획)

사용자가 제공한 실제 협력사 1곳(이하 **협력사 B**, 건설과 엔지니어링)의 자료를 분석했다.
원본 파일에는 실제 회사명·임직원 이름·서명이 있으므로 저장소에 올리지 않는다. 이 문서에는 집계와 판단 예시만 남긴다.

## 1. 받은 자료

| 자료 | 형식 | 내용 |
|---|---|---|
| 자가진단 입력 결과 | 엑셀 1시트 (Click ESG 협력사별 내보내기, `마감V1_입력V1`) | 2025년 66개 정성지표 선택 + 29개 정량 입력값 |
| 증빙 ① `E1-5 …2025.pdf` | **스캔 PDF 5쪽 (글자 없음, 이미지)** | 목표 추진 계획서 (2025.02.07 Rev1, 결재) — 2025년 환경·품질 세부추진 계획 |
| 증빙 ② | **스캔 PDF 3쪽 (이미지)** | 업무분장표 — 노사협의회(사측·근로자측), 환경경영(ISO 14001 책임자·실무자), 서명 포함 |
| 개선계획 이행 | 엑셀 1시트 | 개선과제 6건 (전부 검증결과 N/A 지표), 계획·담당·기한·이행 내용 |

※ 증빙 ①은 같은 파일이 두 번 올라왔다(내용 동일) → 적재 시 **중복 파일 제거** 필요.

## 2. 자가진단 파일 구조 (2단계 적재기 설계 근거)

- 열: 중분류 · 세부지표 · 질문 · **진단(선택 수준)** · 정량 입력항목 · 입력값 · 수준별 선택지 5칸(해당없음/N/A/LOW/MID/TOP) · 입력연도 · 차수 · **세부지표ID**(`SN_SK25SP001`…) · **입력ID**(`BD_SK25SP…`) · **버전ID**(`AL_SK25SP001`) · 정성/정량 · 유형(`CHOICE`/`BIZD`) · 회사코드
- 지표 행(CHOICE) 66개 + 정량 입력 행(BIZD) 29개. 정량 행은 바로 위 지표에 딸린 값.
- 지표 ID에 연도가 들어 있다(`SK25`) → **지표 버전 관리 설계와 딱 맞는다.**

### 수준 → 점수 (확정)
| 수준 | 점수 | 의미 |
|---|---|---|
| TOP | 10 | 최고 수준 |
| MID | 7 | |
| LOW | 3 | |
| N/A | 0 | 하지 않음 / 위반 있음 |
| **해당없음** | **점수 제외** | 해당 사업장 아님, 또는 **위반 사실 없음** |

- 앞서 확인 필요로 남겼던 "위반 지표 6개"는 **감점이 아니라 '해당없음(위반 없음) = 점수에서 제외', 'N/A(위반 있음) = 0점'** 구조다.
- 지표마다 쓰는 수준이 다르다(예: 인증 취득은 N/A·MID·TOP만, 위반 지표는 해당없음·N/A만).

### 협력사 B 선택 분포 (66개)
TOP 27 · MID 10 · LOW 4 · N/A 13 · 해당없음 12

## 3. AI 검증이 할 일을 실제 자료로 본 예시

| 지표 | 협력사 선택 | 증빙에서 확인한 것 | 판정 예시 |
|---|---|---|---|
| 환경 목표 수립 | LOW (문서 내 목표 명시) | 계획서에 2025년 목표(전력요금 전년 대비 10% 절감, 사무용품 10% 절감, 폐기물 적정처리) — 모두 1년 목표, 결재 완료 | **적합** · 3년 이상 중장기 목표가 없어 MID 근거 없음 |
| 환경경영 추진체계 보유 | TOP | 업무분장표에 ISO 14001 총괄책임자(상무)·실무담당자 지정, 목표 추진 현황 모니터링 역할 | 조직·담당자 **확인**, TOP 요건(성과지표·경영진 참여)은 추가 확인 → **확인필요** |
| 환경경영시스템 인증 취득 | TOP (전체 사업장) | 업무분장표에 "ISO 14001 갱신" 언급만 있고 **인증서가 없음** | **증빙누락** · 인증서와 적용 범위 요청 |
| 안전경영시스템 인증 취득 | TOP (전체 사업장) | 받은 자료에 인증서 없음 | **증빙누락** (전체 증빙을 받지 않아 판단 보류) |
| 근로자 피드백/고충처리 절차 | TOP | 노사협의회 사측·근로자측 위원과 역할 지정 | 절차 존재 근거 일부 **확인** |
| 재생에너지 사용량 측정 | N/A | 정량값 "총 전력 소비량 0 MWh"인데, 다른 문항에 Scope2 배출량 69.98 tCO2e · 총 에너지 5,052.93 GJ 입력 | **응답 간 모순** — 전력을 쓰는데 전력 소비량이 0. 규칙 코드로 자동 검출 가능 |
| 장애인 고용률 준수 | TOP | 장애인 6명 / 상시근로자 196명 = 3.06% | 규칙 코드로 법정 의무고용 인원과 비교해 판정 가능 (기준 연도·산정 방식은 설정값으로) |

→ 증빙이 **글자 없는 스캔본**이므로 5단계(증빙 변환)에서 **이미지 판독(OCR 또는 Claude 이미지 입력)**이 필수다.
→ 증빙 파일명이 `E1-5` 같은 코드로 시작한다. **파일 코드 ↔ 지표 연결 규칙**을 확인해야 한다. (예: `E1-5`를 "환경 1중분류 5번째 = 환경경영시스템 인증 취득"으로 보면, 인증서가 아니라 목표 계획서가 올라온 셈이다.)

## 4. 개선계획 파일에서 본 컨설팅 흐름

- 개선과제 6건은 모두 **검증 결과 N/A(0점)** 지표에서 나왔다: 폐기물 감축·재활용 노력, 생물다양성 보전, 분쟁광물 금지 정책, ESG 정보 공시, 전 직원 ESG 교육, 독립적 감사 조직.
- 형식: 지표 · 개선계획(무엇을 증빙으로 낼지, 담당, 기한) · 이행 결과(협력사 서술).
- N/A 지표 13개 중 6개만 과제로 선정됐다 → **개선대상 선정 규칙** 확인 필요.
- 이행 결과는 협력사 서술("정책을 수립하여 제정하였습니다")뿐이다 → 컨설팅 AI가 **이행 증빙이 실제로 붙었는지** 확인하는 역할이 유용하다.

## 5. 추가로 있으면 좋은 것

1. 이 협력사의 **검증 결과**(외주 업체가 확정한 지표별 수준·점수, 검토 내용) — 정답지
2. 이 협력사의 **증빙 전체**(Click ESG 증빙파일 zip) — 받은 2건 외 나머지
3. 증빙 파일명 코드(`E1-5` 등)와 지표의 연결 규칙
4. 개선대상 지표를 고르는 기준 (N/A 전부인지, 영향도 순인지 등)
