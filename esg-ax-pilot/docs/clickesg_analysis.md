# Click ESG 공급망 진단 프로세스 분석 → AX 적용 방안

출처: 공급망 ESG 경영관리 플랫폼 매뉴얼(원청사) v4.80(2025.07.28), ESG 경영관리 플랫폼 소개(2022.8),
사용자 제공 엑셀 2종(산업군 가중치 적용 목록, 공급망 진단 Data 2026-04-23).
※ 엑셀에는 실제 협력사명이 있으므로 저장소에 올리지 않았다. 아래는 집계 값만 기록한다.

## 1. Click ESG 공급망 진단 프로세스 (As-Is)

참여 주체: **원청사**(우리), **협력사**, **검증사**(제3자 검증·실사)

| 단계 | 원청사 | 협력사 | 검증사 |
|---|---|---|---|
| ① 협력사 관리 | 협력사 등록(엑셀 일괄) → 가입요청 메일 → 등록요청 → 진단 대상 설정 | 회원가입 → 등록 동의 | |
| ② 기준정보 관리 | 산업별 가중치(중분류 기준, 합계 100) → 세부지표 선정 → 협력사 산업군(GICS) 적용 | 재무정보 입력 | |
| ③ 리스크 진단(자가진단) | 데이터 등록요청 메일 → 진행 확인 → 공급망 진단(점수 산출) → 마감(Self Assessment 리포트) | 66개 정성 문항 응답 + 증빙 첨부 | |
| ④ 검증 | 검증 요청(온라인 검증 / 오프라인 실사) | | 증빙 확인 → 최종 점수 수정 → 검토의견(총평·영역별) 작성 |
| ⑤ 개선 | 개선대상 지표 선정(자동 규칙 + 수동) → 개선목표 설정 → 개선계획 요청 → 적정성 검토 → 이행률 모니터링 | 개선계획 수립·제출 → 이행 | |
| ⑥ 리포트 | 최종 진단 리포트(종합·산업별·협력사별·개선과제) | | |

협력사 상태값(매뉴얼 기준)
- 가입: 미가입 → 가입완료 → 등록요청 → 등록동의 (또는 등록해제)
- 진단 입력: 미입력 → 입력중 → 입력완료 → 진단완료 → 마감
- 검증: 검증요청 → 검증대기 → 검증완료
- 개선계획: 개선계획요청 → 개선계획등록 → 적정성 검토 → 이행 완료

## 2. 평가 로직

- 지표 점수(0 / 3 / 7 / 10, Lv 척도) → 중분류 점수 × 산업별 가중치 → 영역(E/S/G) 점수 → 종합 점수(10점 만점)
- 위험등급: 고위험 0~2.99 / 중위험 3~6.99 / 저위험 7~10
- ESG 경영등급 7단계: RM-1(최상) ~ RM-7(심각) — 구간 값은 [TBD]
- 가중치 유형: 공통(산업군 기본값) / 커스텀

| 항목 | 값 |

| 기준연도 | 2024 |
| 협력사 수 | 106곳 (가중치 유형 전부 '공통') |
| 산업군(GICS 4단계) | 건설과 엔지니어링 29, IT 컨설팅 및 기타 서비스 28, 애플리케이션 소프트웨어 23, 기술 판매업체 13, 리서치 및 컨설팅 서비스 8, 통신 장비 4, 기술 하드웨어 1 |

## 4. AX 적용 지점 (To-Be)

| Click ESG 단계 | AX Agent | AI가 하는 일 | 사람/코드가 하는 일 |
|---|---|---|---|
| ① 협력사 관리 | 운영 | 가입·등록요청 메일 초안, 미가입 리마인드 초안 | 발송은 사람이 Click ESG에서 |
| ② 기준정보 | 진단 (모듈 A) | 협력사 업종 → GICS 산업군 매핑 제안, Risk Tier 사전 분류 | 가중치 값은 규칙(코드) |
| ③ 자가진단 | 운영 | 미입력/입력중 현황 점검, 리마인드 초안 | 점수 산출은 코드 |
| ④ 검증 | 진단 (모듈 B) | 증빙 vs 응답 정합성, 유효기간, 응답 간 모순 → 판정·근거·조정 점수 제안 | 검증 점수 확정은 전문가, 재계산은 코드 |
| ⑤ 개선 | 컨설팅 | 개선대상 지표별 개선과제 + Best Practice 매칭, 우선순위 제안 | 확정은 전문가 |
| ⑤ 개선 | 운영 | 개선계획 요청 메일 초안, 이행 현황 점검, 만족도 요약 | |
| ⑥ 리포트 | (Step2) | 검토의견서·리포트 초안 | |

파일럿은 Click ESG API 연동이 없으므로, **엑셀 내보내기로 받고 → AX가 처리 → 사람이 Click ESG에 반영**하는 구조다.
필요한 내보내기: 마감 상세 조회의 `입력자료 다운로드`(엑셀), `증빙파일 다운로드`(zip), 산업별 가중치 `Excel Download`, 진단 결과 조회 엑셀.

## 5. 기존 SPEC·1단계 모델에 반영할 사항 (다음 단계 전 확인)

1. 상태 머신에 Click ESG 상태(데이터 등록요청 / 입력중 / 입력완료 / 마감 / 검증요청 / 검증완료 / 개선계획요청 …)를 맞출지
2. `saq_responses`에 선택지 텍스트·Lv 점수, 지표 마스터(영역·중분류·세부지표) 테이블 추가
3. `scores`를 지표 / 중분류 / 영역 / 종합 4단계로, 산업별 중분류 가중치 테이블 추가
4. 협력사 `industry`를 GICS 4단계 경로로 저장
5. 검증 전(협력사 원래 응답)과 검증 후 데이터를 둘 다 받을 수 있는지 → AI 스크리닝 정확도 비교의 정답셋
